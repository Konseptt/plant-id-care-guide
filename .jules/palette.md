## 2024-11-20 - Dynamic ARIA attributes for contextual lists and live regions
**Learning:** Screen readers struggle to distinguish buttons that have identical visible text (e.g., "Write care guide") within a dynamically generated list. Providing a specific, contextual `aria-label` (e.g., "Write care guide for Monstera deliciosa") significantly improves navigation. Additionally, dynamically updating `aria-pressed` on grouped tags, and adding `aria-live` to loading/error areas, ensures asynchronous state changes are reliably communicated.
**Action:** When creating dynamic lists with repetitive action buttons, inject contextual data into `aria-label`. Use `role="status"` with `aria-live="polite"` for loading states, and `role="alert"` with `aria-live="assertive"` for sudden error messages.
